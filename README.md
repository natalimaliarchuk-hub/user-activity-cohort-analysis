# user-activity-cohort-analysis
SQL cohort analysis project analyzing user activity and retention by signup month and promotion group.

## How to Explore This Project

For the best understanding of the analysis, review the project files in the following order:

1. **SQL Analysis (`cohort_analysis.sql`)**  
   Start with the SQL file to see how the data was cleaned, transformed, and analyzed using PostgreSQL. The queries include data preparation, user segmentation, cohort creation, and retention calculations.

2. **Cohort Analysis (`Cohort_analysis.xlsx`)**  
   Open the Excel file to explore the final cohort retention table and the results of the analysis.

3. **Key Insight**  
   The 2025-01-01 cohort demonstrates the strongest retention, suggesting high-quality and loyal organic user acquisition. In contrast, later cohorts show a sharper decline in activity within the first month, which may indicate promotion-driven acquisition, where users tend to disengage after promotional offers end.

## Project Workflow

Raw Data → Data Cleaning → SQL Analysis → Cohort Analysis → Retention Insights
